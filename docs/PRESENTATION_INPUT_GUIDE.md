# Presentation Input Guide

HandGesture Controller is a browser-only presentation tool that uses a webcam and MediaPipe Gesture Recognizer.

## Gesture map

| Gesture | Action |
|---|---|
| Index finger | Laser pointer |
| Victory | Next slide |
| Thumb up | Previous slide |
| Open palm | Fullscreen presentation |

## Presenter setup

Use a well-lit area, keep the hand visible inside the camera frame, and avoid placing the hand directly against a busy background. Upload the presentation PDF before enabling gesture control.

## Debugging

When a gesture appears unreliable, first inspect browser camera permission, lighting, hand position, and whether another application is using the webcam.
