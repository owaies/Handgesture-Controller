# Gesture calibration guide

Reliable gesture control depends on a stable camera view and clear hand visibility.

## Setup
Position the camera so the hand remains inside the recognition area. Use even lighting and avoid strong backlighting.

## Interaction
Use distinct gestures with a brief pause between actions to reduce accidental repeated commands.

## Presentation mode
Test laser pointer tracking, next/previous navigation, and fullscreen separately after changing camera position or viewport size.
