# Gesture Presenter user guide

Gesture Presenter uses a webcam and browser-based gesture recognition to control PDF presentations.

## Controls
- Index finger: laser pointer
- Victory: next slide
- Thumb up: previous slide
- Open palm: presentation/fullscreen mode

## First use
Grant camera permission, load a PDF, and keep the hand visible inside the camera frame. Use deliberate gestures rather than rapid repeated movements.

## Troubleshooting
If gestures are not recognized, check camera permission, lighting, hand visibility, and browser support before changing presentation settings.
